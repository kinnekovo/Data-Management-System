## 4. 手工测试准备

1. 在项目根目录启动系统：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-all.ps1
   ```

2. 浏览器打开 `http://127.0.0.1:5173`。
3. 准备三个账号：
   - 题目创建者：`phase2_owner`；
   - 共享接收者：`phase2_member`；
   - 问卷填写者：`phase2_respondent`。
4. 测试前记录账号密码；各账号用户名不能重复。
5. 以下用例执行后，在“实际结果”中填写页面表现、关键数据和异常信息，并将结果改为 `PASS` 或 `FAIL`。
